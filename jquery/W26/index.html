📚 PICT B.E. Courses

Pune Institute of Computer Technology — B.E. Computer Engineering four-year curriculum.

🟦 FE — First Year Engineering

Semester I
Engineering Mathematics IDifferential calculus, matrices, complex numbers.
Engineering PhysicsOptics, quantum mechanics, semiconductor basics.
Engineering ChemistryOrganic chemistry, polymers, electrochemistry.
Basic Electrical EngineeringDC/AC circuits, transformers, machine fundamentals.
Engineering MechanicsStatics, dynamics, friction, moment of inertia.
Basic ElectronicsDiodes, transistors, basic amplifier circuits.
Semester II
Engineering Mathematics IIIntegration, vector calculus, Fourier series.
Programming in CBasic C syntax, loops, arrays, functions, pointers.
Engineering DrawingOrthographic projections, isometric views, AutoCAD.
Communication SkillsTechnical writing, presentation, professional English.
Workshop PracticeSheet metal, carpentry, fitting lab work.

🟩 SE — Second Year Engineering

Semester III
Data StructuresArrays, linked lists, stacks, queues, trees, graphs.
Discrete MathematicsLogic, sets, relations, graph theory, combinatorics.
Digital ElectronicsBoolean algebra, combinational and sequential logic.
OOP with JavaClasses, inheritance, polymorphism, exception handling.
Computer OrganizationCPU design, memory hierarchy, instruction sets.
Engineering Mathematics IIILaplace transforms, probability, statistics.
Semester IV
Analysis of AlgorithmsComplexity, sorting, searching, graph algorithms.
Database Management SystemsSQL, ER modelling, normalization, transactions.
Operating SystemsProcess scheduling, memory management, file systems.
Microprocessors8086 architecture, assembly language, interfacing.
Software EngineeringSDLC models, requirements, testing methodologies.

🟧 TE — Third Year Engineering

Semester V
Computer NetworksOSI/TCP-IP models, routing, switching, protocols.
Theory of ComputationAutomata, regular expressions, context-free grammars.
System ProgrammingAssemblers, linkers, loaders, macro processors.
Compiler DesignLexical analysis, parsing, semantic analysis, code gen.
Elective IOptions: IoT, Cloud Computing, Information Security.
Semester VI
Artificial IntelligenceSearch algorithms, knowledge representation, ML basics.
Web TechnologiesHTML5, CSS3, JavaScript, Node.js, REST APIs.
Data Warehousing & MiningETL, OLAP, clustering, classification, association rules.
Information SecurityCryptography, network security, ethical hacking basics.
Mini ProjectTeam-based development of a small software project.

🟥 BE — Final Year Engineering

Semester VII
Machine LearningRegression, classification, clustering, neural networks.
High Performance ComputingParallel processing, GPU computing, MPI/OpenMP.
Distributed SystemsConsensus algorithms, consistency, distributed databases.
Elective IIOptions: Deep Learning, Blockchain, NLP.
Project Phase IProblem definition, literature survey, prototype design.
Semester VIII
Big Data AnalyticsHadoop, Spark, MapReduce, real-time stream processing.
Cloud ComputingAWS, Azure, Docker, Kubernetes basics.
